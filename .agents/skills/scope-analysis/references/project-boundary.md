# Tham Chiếu: Project Boundary

## 1. System Boundary

System Boundary xác định:

* Những gì hệ thống chịu trách nhiệm.
* Những gì nằm ngoài trách nhiệm của hệ thống.
* Phần nào do con người thực hiện.
* Phần nào do hệ thống hỗ trợ.

---

## 2. Human vs System

Cần phân biệt rõ:

```text
System
→ Analyze
→ Predict
→ Calculate
→ Recommend
→ Explain

Human
→ Review
→ Adjust
→ Approve
→ Decide
```

---

## 3. Boundary Principle

Không đưa các hoạt động bên ngoài trách nhiệm của DSS vào Core Scope.

Đặc biệt không mặc định rằng:

* AI tự mua hàng.
* AI tự phê duyệt.
* AI tự thanh toán.
* AI thay thế hoàn toàn nhân viên.

---

## 4. Graduation Project Boundary

Khi có tranh luận về việc có nên đưa một chức năng vào project hay không, ưu tiên:

1. Mức độ cần thiết cho Business Problem.
2. Mức độ cần thiết cho Core Workflow.
3. Độ phức tạp.
4. Khả năng triển khai và demo.
5. Giá trị học thuật.
